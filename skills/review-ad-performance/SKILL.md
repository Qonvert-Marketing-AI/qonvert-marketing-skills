# Review existing ad performance

Establish the business goal, relevant conversion, reporting period, time zone and currency. Ask for a campaign, search-term or landing-page report that the user can share in aggregated form. Confirm the conversion window, recent changes and any owner-approved target before drawing conclusions.

1. Reconcile spend, clicks and conversions within the same period and scope. Keep reported conversion value, order value and paid revenue distinct. Compare platforms only when measurement and currency are compatible.
2. Find the strongest signal in the supplied evidence. Check for spend with weak outcomes, clearly irrelevant search terms, broken destinations confirmed by evidence, or a meaningful change in a campaign's performance. Consider reporting lag and data volume before recommending an action.
3. Return up to three priorities. For each, identify the exact campaign or resource, show the evidence and period, and describe an action or verification step. Flag potential side effects such as blocking a relevant query.
4. Give the user the smallest reasonable change to review, the expected directional effect, a check-in date and a rollback or follow-up condition. Keep the change as a proposal until the user approves it.

For search-term report coverage, use [Google Ads Help](https://support.google.com/google-ads/answer/2472708). For Yandex Direct report semantics, use the current [Yandex Direct Help](https://yandex.com/support/direct/en/).
